# 로드맵 — 방학 4단계

원칙: **측정 → 결정화 → 강제 → 자동화** 순서. 자동화는 검증 스토리가 선 뒤에만.
각 단계는 "끝났다고 말할 수 있는 조건"을 가진다. 조건을 못 채우면 다음 단계로 넘어가지 않는다.

## 0단계 — 준비 (지금, 방학 전)

- [x] 강연 논리를 Hermes 운영으로 옮기는 모델 정리 (`docs/01-model.md`)
- [x] 기준선 실측 (`docs/02-baseline.md`)
- [x] 게이트 3종 뼈대 + 실행 스크립트
- [ ] 열린 결정 6개 정리 (`docs/06-open-questions.md`) — 방학 시작 전에 답을 정한다

완료 조건: 게이트가 로컬에서 돌고, 기준선 숫자가 문서와 일치한다.

## 1단계 — 빨간 게이트 끄기 (방학 1주)

목표: 지금 실패/경고인 것을 정리해서 게이트를 초록으로 만든다. 새 기능은 없다.

- [x] 깨진 참조 12건 해결 — 공통 문서 11개 생성(DoD 4종, security 3종, performance 3종, accessibility 1종) + 실존 경로 5건 문장 수정 (2026-11-26, SKL003 오류 0)
- [x] 9,531자 크론 프롬프트 분할 — 절차 본문을 스킬 `hermes-sweeper-runbook`으로 옮기고 프롬프트 2,918자로 축약. 원본 39개 규칙 대조로 유실 0건 확인 (2026-11-26, CRN001 오류 0)
- [x] 메모리 97% → 85% 이하 — 97%→**78%** (19,439→15,648자). 장문 항목 21→5건. 14개 항목을 스킬/참조 문서로 이관하고 코어에는 포인터만 남김 (2026-11-26)
- [x] 게이트를 손으로 깨뜨려 오탐 여부 확인 (특히 SKL003, CRN010) — `--skills-dir` 임시 픽스처로 참조 누락 1건만 정확히 잡는 것 확인 (2026-11-26)

완료 조건: `bash gates/run_all.sh`가 오류 0. 경고는 남아도 되지만 각각 이유가 적혀 있어야 한다.

## 2단계 — 검증 우선 루틴 (방학 2주)

목표: 게이트와 검증을 "가끔 하는 일"에서 "정해진 시점에 반드시 하는 일"로 바꾼다.

- [x] 게이트 실행 시점 확정 (Q4) — **일일 크론**(`slopgate 일일 위생 게이트`, no_agent, 09:00, 토큰 0, 새 위반만 알림) + **CI**(`gates.yml`). 프로젝트 레포 날짜 폭탄은 그 레포 CI에서 (2026-11-26)
- [ ] 판단 대신 증거: PR 리뷰 코멘트에 게이트 출력·실행 로그를 인용하는 형식 정하기
- [ ] 토큰 분포 측정 시작 — `state.db`의 `session_model_usage`로 작업별 사용량 집계 스크립트
- [x] 날짜 린트 게이트 추가 — `gates/date_bomb.py` + `tests/test_gates.py`(39 체크) + CI 워크플로우. 오탐 4종(버전 문자열·맨 정수·hex·URL 쿼리) 제거 확인 (2026-11-26)

완료 조건: 2주 동안 게이트를 건너뛴 PR이 0건. 지표 표에 숫자 2개 이상이 채워짐.

## 3단계 — 정원 가꾸기 (방학 3~4주)

목표: 스킬 인덱스와 스킬 내용을 줄인다. 삭제는 추가보다 어렵고, 그래서 마지막에 한다.

- [ ] 인덱스 예산 확정 후 그 안으로 축소 (Q2) — 지금 118,731자, 후보 예산 60,000~80,000자
- [ ] description 60/120자 규칙 확정 (Q1) — API 제약과 비용 기준을 분리해 문서화
- [ ] `.archive/` 129건 처리 — 살릴 것만 복구, 나머지는 삭제
- [ ] 40,000자 초과 스킬 8개 분할 (인덱스가 아니라 로드 비용)
- [ ] 중복 스킬 탐지 — 같은 트리거를 노리는 스킬 묶음 찾기 (선택 정확도 문제)

완료 조건: 인덱스가 예산 이하이고, 스킬 선택 실패(엉뚱한 스킬 로드) 사례가 줄었다는 관찰 1건.

## 4단계 — 자동화 (방학 이후, 조건 충족 시)

여기서부터는 강연의 "소프트웨어 팩토리"에 해당한다. **자동 머지는 하지 않는다.**

- [ ] 야간 팩토리: 이슈 목록 → 초안 PR 생성 → 게이트 통과 시에만 사람에게 올림
- [ ] 릴리스 후 fuzz/탐색 에이전트 (웹 앱 대상, 예: dcselfie·semo.dcselfie.win)
- [ ] 자동 머지 여부 재검토 — 조건: revert율 측정값이 일정 기간 낮게 유지되고, 리뷰가 잡는 결함이 게이트가 잡는 결함보다 적다는 증거가 있을 때

완료 조건: 사람이 개입한 비율과 자동 처리 비율이 수치로 보고된다.

## 하지 않을 것

- 게이트 없는 자동 수정 PR
- 리뷰 생략
- 볼륨(PR 개수) 목표 설정
